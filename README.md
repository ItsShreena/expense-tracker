# Expense Tracker Dashboard 💸
A modern and responsive Expense Tracker Dashboard built using React + Vite.

Track your income, expenses, savings, and financial activity with interactive charts, analytics, and a premium UI.

---

## 🚀 Features

- 💰 Add income & expense transactions
- 📊 Interactive charts using Recharts
- 👤 Personalized profile section
- 💾 Local storage support
- 🎨 Modern glassmorphism UI
- 📱 Fully responsive dashboard
- ⚡ Fast performance with Vite
- 🧾 Transaction history
- 🗑️ Delete transactions
- 😎 Fun money advice section

---

## 🛠️ Tech Stack

- React
- Vite
- CSS3
- Recharts
- LocalStorage API

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/expense-tracker.git
```

Move into the project folder:

```bash
cd expense-tracker
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
